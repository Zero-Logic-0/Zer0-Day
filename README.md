# ⚡ Zer0-Day

> **Il punto di riferimento indipendente per l'analisi, il confronto e il tracciamento in tempo reale dei modelli LLM.**

Zer0 Day AI è un'applicazione web minimale, ultra-veloce e focalizzata sullo studio e la comparazione delle schede tecniche dei più importanti modelli di linguaggio naturale (LLM), sia proprietari che Open Source.

---

## 🌟 Funzionalità Principali

* ** Enciclopedia LLM Completa:** Schede tecniche dettagliate per ogni modello (Architettura, Linguaggi supportati, Piattaforme di Coding, Requisiti Hardware).
* **⚡ Live Comparison Lab:** Strumento per confrontare affiancati 2 modelli di intelligenza artificiale per valutarne istantaneamente differenze e benchmark.
* ** Prossimi LLM in Arrivo:** Sezione dedicata ai modelli di nuova generazione in fase di addestramento o test di sicurezza (es. GPT-5, Llama 4, Claude 3.5 Opus).
* **🔍 Ricerca & Filtro Dinamico:** Filtra per modelli Proprietari, Open Source o esegui ricerche istantanee per sviluppatore o parole chiave.
* **🎨 Interfaccia Dark Mode Minimal:** Design monocromatico responsive ad alte prestazioni, curato per sviluppatori, ricercatori e appassionati di IA.

---

## 🛠️ Tech Stack

Il progetto è sviluppato seguendo la filosofia dell'estrema leggerezza e velocità d'esecuzione:

* **HTML5 & Vanilla JavaScript (ES6+):** Zero framework pesanti, zero dipendenze complesse.
* **Tailwind CSS (via CDN):** Styling minimale basato su palette custom monocromatica.
* **FontAwesome:** Iconografia vettoriale per le specifiche tecniche.
* **GitHub Pages:** Hosting automatico e continuo con certificato SSL (HTTPS).
